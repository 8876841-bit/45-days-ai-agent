# Day 2：Self-Attention 与 QKV

今天目标：理解 self-attention 如何让每个 token 根据上下文更新自己的表示。

核心公式：

```text
Attention(Q, K, V) = softmax(QK^T / sqrt(d_k))V
```

先记住一句话：

```text
scores 是“像不像”，weights 是“看多少”，output 是“混合后的新表示”。
```

## 1. 为什么要手写 NumPy attention

真实 Transformer 里的 attention 有很多矩阵、batch、head 和 mask。第一天直接看完整实现很容易迷路。

所以 Day 2 先用 3 个 token 做最小实验：

```text
我
喜欢
AI
```

并人为给它们设置小向量：

```text
我    = [1.0, 0.0, 0.0]
喜欢  = [0.8, 0.2, 0.0]
AI    = [0.0, 0.1, 1.0]
```

这个向量不是模型真实学出来的语义，而是为了演示 attention 的机制。

## 2. 向量坐标的标准是什么

在真实模型里，token 向量是训练出来的，不是人手工设计的。

但在这个实验里，我们人为设置向量，是为了制造一个容易观察的关系：

```text
如果两个向量方向接近，它们就更像。
如果两个向量方向差很远，它们就不太像。
```

例如：

```text
我    = [1.0, 0.0, 0.0]
喜欢  = [0.8, 0.2, 0.0]
```

它们都主要集中在第 1 个维度，所以比较像。

而：

```text
AI = [0.0, 0.1, 1.0]
```

它主要集中在第 3 个维度，所以和前两个不太像。

可以临时把这 3 个维度想成：

```text
第 1 维：偏“人/动作上下文”
第 2 维：轻微连接维度
第 3 维：偏“AI/技术概念”
```

注意：这只是教学用。真实模型可能有几千维，而且每一维不一定能被人类直接命名。

## 3. Attention scores 是什么

实验里会打印：

```text
Attention scores = QK^T / sqrt(d_k)
```

这一步是在算：每个 token 和其他 token 有多像。

在我们的简化实验里，先把 Q、K、V 都设成同一个输入向量 `x`：

```text
q = x
k = x
v = x
```

所以可以先理解为：

```text
scores = 向量点积 / sqrt(维度数)
```

例如“我”和“喜欢”：

```text
我    = [1.0, 0.0, 0.0]
喜欢  = [0.8, 0.2, 0.0]
```

点积：

```text
1.0 * 0.8 + 0.0 * 0.2 + 0.0 * 0.0 = 0.8
```

向量维度是 3，所以除以：

```text
sqrt(3) ≈ 1.732
```

得到：

```text
0.8 / 1.732 ≈ 0.462
```

因此输出表中会看到：

```text
我 -> 喜欢 = 0.462
```

意思是：

```text
当“我”这个 token 去看“喜欢”这个 token 时，它们的相似度分数是 0.462。
```

## 4. Q、K、V 怎么理解

今天先用最朴素的记法：

```text
Q = Query，我在找什么
K = Key，我有什么标签
V = Value，我的实际内容
```

模型会用 Q 和 K 计算相关性：

```text
QK^T
```

然后用相关性去加权汇总 V：

```text
weights @ V
```

所以：

```text
Q 和 K 决定“看谁”
V 决定“拿到什么信息”
```

在真实模型里，Q、K、V 不是直接等于输入向量，而是由输入向量乘上三个可学习矩阵得到：

```text
Q = XWq
K = XWk
V = XWv
```

Day 2 的实验先省略这一步，是为了看清 attention 主流程。

## 5. 为什么要除以 sqrt(d_k)

如果向量维度很高，点积结果容易变大。

分数太大时，softmax 会变得很极端。例如：

```text
[20, 1, 0]
```

经过 softmax 后，几乎所有注意力都会给第一个位置。

这样模型训练会不稳定，也不利于细腻地分配注意力。

所以要除以：

```text
sqrt(d_k)
```

这一步叫 scaling，用来让分数保持在更温和的范围里。

## 6. Attention weights 是什么

scores 只是原始分数，还不是最终比例。

下一步是：

```text
weights = softmax(scores)
```

softmax 会把每一行分数变成比例，并且每一行加起来约等于 1。

例如：

```text
我 -> 我     0.408
我 -> 喜欢   0.363
我 -> AI     0.229
```

意思是：

```text
当模型更新“我”这个 token 的表示时：
40.8% 看“我”
36.3% 看“喜欢”
22.9% 看“AI”
```

这就是 attention 的核心：每个 token 都会给上下文里的其他 token 分配注意力比例。

## 7. Output vectors 是什么

最后一步：

```text
output = attention_weights @ V
```

意思是：用注意力比例，把其他 token 的信息混合进当前 token。

例如原始的“我”是：

```text
我 = [1.0, 0.0, 0.0]
```

经过 attention 后可能变成：

```text
我 = [0.698, 0.096, 0.229]
```

它不再只是原来的“我”，而是混入了“喜欢”和“AI”的上下文信息。

这就是为什么 attention 后的向量叫“上下文化表示”。

## 8. Case 2 在观察什么

实验里第二组输入把“喜欢”改得更像“AI”：

```text
喜欢 = [0.1, 0.0, 0.9]
AI   = [0.0, 0.1, 1.0]
```

于是你会看到：

```text
喜欢 -> AI 的 attention weight 变高
```

这说明 attention 权重不是固定的，而是由 token 向量之间的相似度决定的。

## 9. 今日总结

今天只需要吃透 4 个词：

```text
input vectors：每个 token 原本的信息
scores：两两相似度
weights：每个 token 应该关注谁、关注多少
output：混合上下文后的新 token 表示
```

最终理解：

```text
Self-Attention 会让每个 token 看一遍上下文，决定关注谁，然后把被关注 token 的信息按比例混进自己的新表示里。
```
