# 45天人工智能代理

这是一个面向 AI Agent 的 45 天系统化学习与实战计划，目标是在 45 天内完成从底层概念、Agent 核心机制、多 Agent 架构到毕业项目作品集的闭环。

## 文档目录

- [45天AI技能体系化掌握打卡计划](./45-days-ai-agent-plan.md)
- [45天AI Agent高强度训练计划：每天6小时版](./45-days-ai-agent-6h-intensive.md)
- [Windows 11 + 中国大陆网络 AI 学习环境配置建议](./windows-mainland-ai-env-setup.md)

## 训练目标

- 理解 Transformer、Token、Embedding、Attention、采样和上下文窗口
- 掌握 Agent 的 messages、Tool Use、RAG、ReAct、Memory 和 Eval
- 能实现一个个人助理 Agent
- 能理解并实践多 Agent 架构
- 完成一个可展示的毕业项目
- 最终沉淀为 GitHub 作品集、技术博客和 Demo 视频

## 推荐执行方式

如果每天时间有限，使用 `45-days-ai-agent-plan.md`。

如果每天能投入 6 小时高强度学习，使用 `45-days-ai-agent-6h-intensive.md`。

正式开始前，先阅读 `windows-mainland-ai-env-setup.md` 完成 Day 0 环境准备。
